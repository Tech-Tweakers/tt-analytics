Monitoramento continuo de qualidade de codigo para os repositorios da Tech Tweakers.

### Rework Rate

Identifica retrabalho no codigo — linhas modificadas repetidamente num curto periodo.
Quanto menor, mais eficiente o ciclo de desenvolvimento.

</div>

<div className="feature-card">
<span className="feature-icon">📊</span>

### Code Churn

Mede a volatilidade do codigo: volume de adicoes e delecoes ao longo do tempo.
Picos de churn indicam areas instaveis que precisam de atencao.

</div>

<div className="feature-card">
<span className="feature-icon">🛠️</span>

### Refactor Rate

Detecta commits de refatoracao vs commits de logica de negocio.
Ajuda a balancear divida tecnica com entrega de features.

</div>

### Como funciona

As metricas sao calculadas automaticamente a partir dos commits via GitHub API.
Pipelines escalonados rodam ao longo da semana, analisando lotes de repositorios
sem estourar rate limits.

<div className="info-box">
Cada repositorio tem 3 dashboards interativos com graficos Plotly, tabelas de ranking
por autor e exportacao CSV. Navegue pela sidebar para explorar.
</div>
